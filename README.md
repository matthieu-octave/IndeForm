# Indé’Form

Solution pour les formateurs indépendants, éditée par MOWD.

| Dossier | Module |
|---|---|
| `compte/` | Compte Indé’Form : comptes, espaces de travail, connexion unique (socle de la suite) |
| `form-studio/` | Form’Studio : préparer et réutiliser ses cours |
| `form-pilot/` | Form’Pilot : planning, interventions, préparation de facturation (à importer depuis `H:\IndéGest`) |
| `docs/` | Décisions et synthèse de la conversation Codex |
